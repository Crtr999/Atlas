# CBC Assistant Generation Guide

This folder contains everything you need to regenerate the CBC Assistant HTML from the Excel data.

## Files

### Data Files
- **CBC_Settlement_Funding_Master_v4.xlsx** - Master data file with all cases, jurisdictions, court access info
- **CBCAssistant_Complete.html** - Final working HTML application

### Generation Scripts
- **regenerate_cbc_assistant_v7_complete.py** - Generates HTML from Excel data
- **enhance_all_features_clean.py** - Adds search bar, approvals, sorting, etc.

## How to Regenerate

When you update the Excel file and want to regenerate the HTML:

### Step 1: Update Excel
Edit `CBC_Settlement_Funding_Master_v4.xlsx`:
- Add cases to **Cases** sheet
- Add county notes to **Jurisdictions** sheet (County_Notes column)
- Update court access info in **Court Access** sheet

### Step 2: Run Generation Scripts

```bash
# Generate base HTML from Excel
python3 regenerate_cbc_assistant_v7_complete.py

# Add all UI enhancements (search, approvals, sorting, etc.)
python3 enhance_all_features_clean.py
```

The final file will be: **CBCAssistant_Complete.html**

## What Each Script Does

### regenerate_cbc_assistant_v7_complete.py
- Reads all 6 Excel sheets
- Extracts 127 cases with status categorization (Approved/Dismissed/Denied)
- Builds jurisdiction records for all 3,140 counties
- Uses fuzzy matching to link county names (e.g., "Ramsey" → "Ramsey County")
- Embeds all data as JSON in the HTML
- Creates the base HTML structure

### enhance_all_features_clean.py
- Adds standalone search bar (searches all 3,140 counties)
- Adds Approvals tracking to county cards, judge cards, and stats bar
- Reorders stats: Approved → Dismissed → Denied
- Adds sorting by case count (most active counties first)
- Displays county notes (Ramsey, James City, Fresno)
- Adds all CSS styling for new features

## Features in Final HTML

✓ All 3,140 counties from Atlas document

✓ Counties sorted by case count
✓ Jurisdiction-specific notes display
✓ Court access info with Westlaw badges
✓ State filtering
✓ Expandable county and judge cards

## Script Requirements

The scripts expect:
- Python 3 with pandas and openpyxl installed
- Excel file: `CBC_Settlement_Funding_Master_v4.xlsx` in the same directory
- Template file: `CBCAssistant_v4.html` (the original template)

If you don't have the original template, the regeneration script will fail. In that case, you can extract it from an existing HTML file or ask Claude to help.

## Troubleshooting

**"Template not found"**
→ Make sure `CBCAssistant_v4.html` is in the same directory, or update the path in the script

**"Excel file not found"**
→ Check that `CBC_Settlement_Funding_Master_v4.xlsx` is in the same directory

**"No module named pandas"**
→ Install dependencies: `pip install pandas openpyxl`

**County notes not appearing**
→ Make sure notes are in the **Jurisdictions** sheet in the **County_Notes** column
→ County names must match between sheets (the script uses fuzzy matching for "County" suffix)
